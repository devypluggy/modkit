[h1]Моды для The Forest без ModAPI[/h1]

[b]Лёгкий загрузчик модов на базе UnityDoorstop.[/b]
Он [b]не изменяет файлы игры[/b]: Assembly-CSharp.dll остаётся оригинальным, Steam «Проверка целостности» ничего не ломает. ModAPI не нужен. Удаление — стереть файлы лоадера.

[b]Скачать:[/b] [url=https://github.com/devypluggy/modkit/releases]GitHub Releases[/url]
[b]Исходный код:[/b] [url=https://github.com/devypluggy/modkit]GitHub[/url]

[h2]Что это даёт[/h2]
[list]
[*]Кладёшь .dll в папку [b]DllMods[/b] — мод грузится сам при запуске.
[*]Ничего не патчится: никаких бэкапов, «восстановить оригиналы» и сломанных обновлений.
[*]Вес самого лоадера — меньше 50 КБ, лаунчер — около 120 КБ.
[*]Моды собираются встроенным в Windows компилятором C# 3.0, .NET SDK не нужен.
[/list]

[h2]Чего он не делает[/h2]
Он [b]не запускает готовые моды ModAPI[/b] (Ultimate Cheatmenu, Map, BetterBlueprints и т.п.) — там другая архитектура. Это база для своих модов и лёгкая альтернатива патчеру.

[h2]Требования[/h2]
[list]
[*]The Forest в Steam, [b]TheForest.exe[/b] (x64) или [b]TheForest32.exe[/b] (x86)
[*]Windows 10/11
[*]Лаунчер сам определяет разрядность exe и ставит нужный прокси (x64 или x86)
[/list]
[quote]В одной папке не могут лежать x64- и x86-прокси одновременно. Если в копии есть оба exe, установщик выбирает 64-битный. Для 32-битной версии ставь лоадер отдельно с флагом -X86 (см. README).[/quote]

[h2]Установка (2 минуты)[/h2]
[b]Самый простой способ:[/b] скачай [b]ForestModLoader.exe[/b] из Releases, запусти и нажми «Установить». Лаунчер сам найдёт игру, поставит нужные файлы и предложит запустить её.
[b]1.[/b] Или скачай архив из Releases и распакуй его.
[b]2.[/b] В Steam: ПКМ по игре → Управление → Просмотреть локальные файлы.
[b]3.[/b] Скопируй в эту папку (рядом с TheForest.exe) из папки [b]doorstop\[/b]:
[code]winhttp.dll
doorstop_config.ini
Doorstop.dll[/code]
[quote]Для 32-битной игры скопируй [b]winhttp_x86.dll[/b] и переименуй его в [b]winhttp.dll[/b]. Оба прокси в одной папке не работают.[/quote]
[b]4.[/b] Создай папку [b]DllMods[/b] и положи туда моды (.dll).
[b]5.[/b] Запускай игру [b]обычным способом через Steam[/b].

[quote]Не запускай игру через ModAPI.exe — он патчит Assembly-CSharp.dll и будет конфликтовать с лоадером.[/quote]

[h2]Как проверить, что всё работает[/h2]
Дойди до главного меню и открой в папке игры файл [b]doorstop_loader.log[/b]. В нём должно быть примерно так:
[code][2026-11-05 19:20:47] Doorstop.Start, base=...\The Forest
[2026-11-05 19:20:47] subscribed to SceneManager.sceneLoaded
[2026-11-05 19:21:33] ModHost created
[2026-11-05 19:21:37] found mods: 1
[2026-11-05 19:21:37] loaded assembly: ТвойМод
[2026-11-05 19:21:37] Init called: ТвойМод[/code]
Если папка игры защищена от записи (например, Program Files без прав администратора), лог будет здесь: [b]%LOCALAPPDATA%\TheForestModLoader\doorstop_loader.log[/b].
Если файла нет ни там, ни там — лоадер не подхватился, смотри раздел «Если не работает».

[h2]Как написать свой мод[/h2]
Нужен публичный статический метод [b]Init()[/b] без параметров. Он вызывается автоматически после загрузки первой сцены:
[code]using UnityEngine;

public static class MyMod
{
    public static void Init()
    {
        GameObject go = new GameObject("MyMod");
        Object.DontDestroyOnLoad(go);
        go.AddComponent&lt;MyBehaviour&gt;();
    }
}

public class MyBehaviour : MonoBehaviour
{
    private void Update()
    {
        if (Input.GetKeyDown(KeyCode.F7))
        {
            // твой код
        }
    }
}[/code]
Скомпилируй под .NET 3.5 (C# 3.0) с ссылками на [b]UnityEngine.dll[/b], [b]Assembly-CSharp.dll[/b] и [b]TheForest.Modding.dll[/b] из папки игры, положи DLL в [b]DllMods\[/b] — готово.

[b]Важно:[/b] в [b]Init()[/b] игрок (LocalPlayer) ещё может быть null. Игровую логику держи в [b]Update()[/b] и проверяй на null.

[h2]Если не работает[/h2]
[list]
[*][b]Нет doorstop_loader.log[/b] — проверь [b]%LOCALAPPDATA%\TheForestModLoader\[/b]; иначе winhttp.dll лежит не рядом с TheForest.exe, скачана версия не той разрядности или антивирус удалил файл.
[*][b]Лог есть, но нет Init called[/b] — мод не в DllMods, метод Init не public static или с параметрами, либо сборка не загрузилась (в логе строка mod load error).
[*][b]Init called есть, но в игре ничего[/b] — логика выполнилась до появления LocalPlayer, перенеси её в Update().
[*][b]Игра не запускается с ошибкой 0xc000007b[/b] — не совпала разрядность прокси. Замени winhttp.dll на версию под свою игру (x64 или x86).
[*][b]Игра не запускается[/b] — удали winhttp.dll и doorstop_config.ini, игра вернётся в исходное состояние.
[/list]
Лог самой игры: [b]%USERPROFILE%\AppData\LocalLow\SKS\The Forest\output_log.txt[/b]

[h2]Удаление[/h2]
Удали из папки игры файлы лоадера:
[code]winhttp.dll
doorstop_config.ini
Doorstop.dll
doorstop_loader.log
DllMods\SampleCheats.dll[/code]
Свои моды в [b]DllMods\[/b] можно оставить — лоадер их просто перестанет загружать. Игра останется абсолютно нетронутой.

[h2]Совместимость[/h2]
[list]
[*]The Forest (Steam), Unity 5.6.5, x64 и x86
[*]Не совместим по одновременному запуску с ModAPI: запускай игру напрямую через Steam
[*][b]VR не поддерживается:[/b] TheForestVR.exe не загружает winhttp.dll, поэтому Doorstop в VR-режиме не работает
[*]После обновления игры Steam может перезаписать winhttp.dll — просто скопируй его обратно
[/list]
